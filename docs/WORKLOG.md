# 제작 과정 기록

2026-10-01, Claude Code로 진행한 작업을 순서대로 정리한 문서입니다.

## 목표와 조건

- 실습 주제: **MCP를 사용해서 홈페이지 만들기**
- MCP는 제작 단계에서만 사용합니다. 완성된 홈페이지는 LLM이나 MCP를 호출하지 않는 정적 사이트여야 합니다.
- API 키 발급 없이 진행합니다.

## 1. MCP 검토

| MCP | 결과 | 이유 |
|---|---|---|
| KIS_MCP_Server | 사용 안 함 | 세션에 등록되어 있지 않았고, 주제와 무관 |
| flor3z-github/navermap-mcp-server | 사용 안 함 | 지오코딩·길찾기·정적 지도만 있고 장소 검색이 없음. 네이버 클라우드 플랫폼 키 필요 |
| yunkee-lee/mcp-naver-maps | 사용 안 함 | 지역 검색은 되지만 키가 2종(네이버 클라우드 플랫폼, 네이버 개발자센터) 필요 |
| **Playwright MCP** | **채택** | 이미 연결되어 있었고 키가 필요 없음. 브라우저로 네이버 지도 검색 결과를 읽을 수 있음 |

Playwright MCP는 두 가지 용도로 썼습니다.

- **데이터 수집**: 네이버 지도의 "<지역> 캠핑장" 검색 결과 읽기
- **동작 확인**: 만든 페이지를 열어 검색, 필터, 상세 팝업, 모바일 화면 테스트

## 2. 첫 버전

- 구성: `index.html`, `css/style.css`, `js/app.js`, `data/campsites.js`
- 데이터: 17개 시·도를 검색해 지역별 상위 12곳씩 188곳
- 지도: 처음에는 네이버 지도 JavaScript API를 쓰려 했으나 키가 필요해, Leaflet + OpenStreetMap으로 변경
- 데이터 파일을 JSON이 아닌 전역 변수(`window.CAMPSITES`)로 둔 이유: `index.html`을 더블클릭(`file://`)해도 열리게 하기 위함

## 3. 사용자 피드백 반영

받은 지적은 두 가지였습니다.

1. "수원", "강원" 등을 넣어도 동작하지 않는다.
2. 별점 같은 정보가 없어 실사용자에게 필요한 내용이 없다.

### 원인

- 데이터가 시·도별 상위 12곳뿐이라 수원 캠핑장이 아예 없었습니다.
- "내 주변" 버튼이 브라우저 위치만 사용했고, 지명 입력을 받지 않았습니다.
- 이름·주소·한줄 요약만 수집했습니다.

### 수정

- **수집 범위 확대**: 17개 시·도에 주요 시·군 약 95곳을 더해 다시 수집 → 약 3,300곳
- **수집 항목 추가**: 대표 사진, 방문자 리뷰 수, 블로그 리뷰 수, 별점, 1박 최저가, 네이버 예약 가능 여부
- **지역 주변 찾기**: 입력값을 아래 순서로 해석
  1. 시·도 이름이면 지역 탭으로 전환
  2. 시·군·구 이름이면 그 지역 캠핑장들의 중심을 기준 위치로 사용
  3. 캠핑장 이름과 맞으면 글자 검색 결과 표시
  4. 그 밖의 지명은 OpenStreetMap 지명 검색(Nominatim)으로 좌표 조회
- **조건 필터, 정렬, 더 보기(30곳씩)** 추가
- 위치 권한 실패 시 경고창 대신 안내 문구 표시

## 4. 디자인 적용

- `npx getdesign@latest add airbnb`로 `DESIGN.md` 설치
- 가이드에 따라 전면 수정: 흰 바탕, 포인트 색 하나(#ff385c), 알약형 검색창과 원형 검색 버튼, 밑줄형 지역 탭, 사진 중심 카드, 큰 숫자 별점 표시
- 가이드와 다르게 한 부분: Airbnb 전용 글꼴은 시스템 글꼴로 대체, Airbnb 로고·일러스트는 사용하지 않음

## 5. 3D 워크플로 페이지

- `workflow.html`, `js/workflow.js` 추가 (Three.js r160)
- 제작 과정 6단계(요청 → 수집 → 정리 → 디자인 → 제작 → 확인)를 경로 위의 3D 도형으로 표현
- 4.5초마다 자동 전환, 도형이나 단계 설명을 누르면 해당 단계로 이동
- 움직임 줄이기 설정(`prefers-reduced-motion`)이 켜져 있으면 자동 재생과 흔들림을 끔

## 6. 업데이트 스크립트

- `tools/update-campsites.js` 추가. 실행: `npm run update`
- 검색 결과 페이지의 HTML에 데이터가 포함되어 있어, 브라우저 없이 Node의 `fetch`만으로 수집 가능함을 확인
- 결과가 급감하면 덮어쓰지 않는 안전장치와 백업 파일 추가
- 실제 실행 결과: 112개 지역 검색, 3,296곳 수집(신규 6, 빠짐 7), 약 4분

사용법은 [README](../README.md#데이터-업데이트)에 있습니다.

## 겪은 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 카드 사진이 전부 안 뜸 | 네이버 이미지 서버는 정해진 크기만 허용 (`f480_480` 불가) | 허용되는 `f640_640`, `w750_sharpen` 사용 |
| 모바일에서 목록이 화면 밖으로 넘침 | 그리드 열 너비가 줄바꿈 없는 제목 길이에 맞춰 늘어남 | 열을 `minmax(0, 1fr)`로 지정 |
| "자라섬" 검색이 전북 완주로 잡힘 | 같은 이름의 다른 장소 | 지명 검색을 쓴 경우 기준 위치를 화면에 표시 |
| 지명 검색 응답이 늦게 와서 다른 검색을 덮어씀 | 비동기 응답 순서 | 입력값이 바뀌었으면 응답을 버림 |
| 전국 지도가 점으로 뒤덮임 | 3,000개 넘는 마커 | 개수에 따라 점 크기 축소, 캔버스 렌더링 사용 |
| 3D 문서·창 도형이 옆면만 보임 | 납작한 도형을 한 바퀴 회전 | 좌우로만 흔들리게 변경 |
| 첫 push가 "Repository not found" | PC에 다른 GitHub 계정 로그인 정보가 저장됨 | 원격 주소에 계정 이름을 지정 |

## 확인한 것과 확인하지 못한 것

확인한 것 (Playwright MCP로 실제 브라우저에서):

- 지역 주변 찾기(수원, 가평, 해운대), 시·도 탭 전환(강원), 조건 필터, 정렬, 더 보기, 상세 팝업
- 사진 표시, 네이버 지도 링크, 데스크톱(1440px)과 모바일(390px) 화면
- 3D 페이지의 자동 전환, 단계 클릭, 도형 클릭
- 배포된 GitHub Pages 주소에서의 동작
- 업데이트 스크립트 전체 실행

확인하지 못한 것:

- "내 위치에서 찾기"의 실제 위치 권한 허용 흐름 (테스트 브라우저가 위치를 주지 않아, 가짜 좌표로 정렬·거리 계산만 확인)
- `index.html`을 더블클릭(`file://`)해서 여는 경우
- Windows 작업 스케줄러 등록
- 3D를 지원하지 않는 브라우저에서의 대체 화면
