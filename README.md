# 전국 캠핑장 안내

지역 이름을 입력하면 그 주변 캠핑장을 가까운 순으로 보여 주는 정적 웹사이트입니다.

- 사이트: https://herojyd-maker.github.io/camping-guide/
- 제작 과정(3D): https://herojyd-maker.github.io/camping-guide/workflow.html

서버 프로그램, DB, API 키 없이 HTML·CSS·JS 파일만으로 동작합니다. 캠핑장 데이터는 `data/campsites.js` 한 파일에 들어 있으며, 실시간으로 갱신되지 않으므로 [주기적으로 업데이트](#데이터-업데이트)해야 합니다.

## 기능

- **지역 주변 찾기**: "수원", "가평"처럼 지역 이름을 넣으면 그 지역 기준 가까운 순으로 정렬
- **내 위치에서 찾기**: 브라우저 위치 정보로 가까운 캠핑장 정렬 (HTTPS 또는 localhost에서 동작)
- **지역 탭**: 16개 시·도별 보기
- **조건 필터**: 오토캠핑, 글램핑, 카라반, 차박, 반려동물, 수영장, 계곡, 바닷가, 예약 가능
- **정렬**: 리뷰 많은 순, 별점 높은 순, 가격 낮은 순, 가까운 순
- **지도**: Leaflet + OpenStreetMap
- **상세 보기**: 사진, 별점, 리뷰 수, 가격, 시설, 전화, 네이버 지도 링크

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 메인 페이지 |
| `workflow.html` | 제작 과정을 Three.js 3D 애니메이션으로 보여 주는 페이지 |
| `css/style.css` | 스타일 (디자인 토큰은 `DESIGN.md` 기준) |
| `js/app.js` | 검색, 필터, 정렬, 지도, 상세 팝업 |
| `js/workflow.js` | 3D 워크플로 장면 |
| `data/campsites.js` | 캠핑장 데이터 (스크립트가 생성, 직접 수정하지 않음) |
| `tools/update-campsites.js` | 데이터 업데이트 스크립트 |
| `DESIGN.md` | `npx getdesign@latest add airbnb`로 설치한 디자인 가이드 |
| `docs/WORKLOG.md` | 제작 과정 기록 |

## 내 PC에서 실행

```bash
npm start
```

http://127.0.0.1:8765/ 로 접속합니다. `index.html`을 더블클릭해서 열어도 되지만, "내 위치에서 찾기"는 브라우저에 따라 막힐 수 있습니다.

## 데이터 업데이트

데이터는 수집한 날짜의 스냅샷입니다. 가격, 전화번호(0507 안심번호), 폐업·신규 캠핑장, 리뷰 수가 바뀌므로 **월 1회** 업데이트를 권합니다. 가격 변동이 큰 봄·여름 시즌 직전에는 한 번 더 하면 좋습니다.

### 필요한 것

- Node.js 18 이상
- 추가 설치, API 키, 브라우저는 필요 없습니다.

### 순서

```bash
# 1. 데이터 다시 수집 (약 4분)
npm run update

# 2. 내 PC에서 확인
npm start

# 3. 사이트에 반영
git add -A
git commit -m "Update campsite data"
git push
```

push하고 1~2분 뒤 GitHub Pages에 자동 반영됩니다. 화면 아래의 "수집" 날짜가 바뀌었는지 확인하세요.

### 스크립트가 하는 일

1. 네이버 지도에서 "서울 캠핑장", "가평 캠핑장" 등 112개 지역을 1.2초 간격으로 검색합니다.
2. 중복을 없애고 캠핑 업종만 골라 시·도별로 분류합니다.
3. 직전 파일을 `data/campsites.backup.js`로 보관한 뒤 `data/campsites.js`를 새로 씁니다.
4. 캠핑장 수와 신규·빠진 곳의 수를 출력합니다.

### 안전장치

아래 경우에는 기존 파일을 덮어쓰지 않고 종료합니다.

- 수집된 캠핑장 수가 기존의 70% 미만일 때
- 검색 실패가 전체의 10%를 넘을 때

네이버가 페이지 구조를 바꾸거나 요청을 차단하면 이렇게 됩니다. 결과를 확인한 뒤에도 덮어쓰려면 다음과 같이 실행합니다.

```bash
node tools/update-campsites.js --force
```

업데이트 후 문제가 있으면 `data/campsites.backup.js`를 `data/campsites.js`로 복사해 되돌립니다.

### 검색 지역 바꾸기

`tools/update-campsites.js`의 `QUERIES` 배열에 지역 이름을 추가하거나 뺍니다. 이름이 겹치는 지역은 "경기 광주", "강원 고성"처럼 시·도를 붙입니다.

### 매월 자동 실행 (선택)

Windows 작업 스케줄러에 등록하면 매월 1일 오전 9시에 수집합니다. 경로는 이 저장소를 받은 위치로 바꿉니다.

```powershell
schtasks /Create /SC MONTHLY /D 1 /ST 09:00 /TN "CampsiteUpdate" /TR "cmd /c cd /d C:\경로\camping-guide && npm run update"
```

자동 실행은 수집까지만 합니다. 사이트 반영(`git push`)은 결과를 확인한 뒤 직접 합니다.

## 알아둘 점

- **데이터 출처**: 캠핑장 정보와 사진은 네이버 지도 검색 결과에서 가져온 것입니다. 사진은 네이버 서버에서 직접 불러옵니다. 네이버 이용약관과 사진 저작권 문제가 있을 수 있으므로 상업적 이용이나 대규모 공개에는 적합하지 않습니다. 그런 용도라면 한국관광공사 고캠핑 공공 API로 데이터 출처를 바꾸는 것을 권합니다.
- **네이버 구조 의존**: 업데이트 스크립트는 네이버 검색 결과 페이지의 내부 데이터 형식에 의존합니다. 네이버가 개편하면 스크립트 수정이 필요합니다.
- **가격**: 수집 시점의 1박 최저가이며 실제 가격과 다를 수 있습니다.
- **별점**: 네이버가 별점을 제공하는 일부 캠핑장에만 표시됩니다.
- **거리**: 직선거리입니다.
- **지명 검색**: 시·군·구 이름은 수집한 데이터로 위치를 계산합니다. 그 밖의 지명은 OpenStreetMap 지명 검색(Nominatim)을 쓰며, 같은 이름의 다른 장소가 잡힐 수 있어 화면에 기준 위치를 표시합니다.
- **외부 의존**: 지도 타일(OpenStreetMap), Leaflet·Three.js(unpkg)를 인터넷에서 불러옵니다.
